# Accessibilité et modes dégradés

## Principes

- les informations essentielles ne dépendent pas du viewer 3D ;
- les cartes et graphiques possèdent une alternative textuelle ;
- les statuts ne reposent pas uniquement sur la couleur ;
- le clavier permet les actions de revue ;
- les focus et erreurs sont explicites ;
- les médias possèdent des descriptions lorsque disponibles.

## Modes dégradés

### API partiellement indisponible

Afficher les métadonnées disponibles et signaler les sections manquantes.

### Asset spatial absent

Maintenir la chronologie, les faits et les sources sans inventer de visualisation.

### WebGL indisponible

Afficher les informations textuelles et les téléchargements autorisés.

### Analyse non disponible

Afficher le média et son statut sans produire de résultat simulé.

### Incertitude élevée

Afficher l’abstention ou l’enveloppe, pas un point arbitraire.

## Admin

Les décisions critiques exigent :

- libellé explicite ;
- confirmation ;
- raison ;
- retour d’état ;
- audit.
