# Contrat de l’interface de revue

## Principe

L’interface présente les preuves, propositions et incertitudes sans confondre observation, interprétation et publication.

## Panneaux

- média source ou frame ;
- boîtes D-FINE et RT-DETRv2 ;
- masque candidat ;
- heatmap et ancrage ;
- transcription ;
- OCR ;
- observations Ministral ;
- contradictions ;
- rendus candidats ;
- correspondances 2D-3D ;
- pose ;
- raycast ;
- enveloppe d’incertitude ;
- reason codes.

## Actions

- accepter, corriger ou rejeter un fait ;
- corriger un masque ;
- déplacer, supprimer ou rejeter un point ;
- invalider des correspondances ;
- imposer une abstention ;
- valider ou rejeter une géométrie ;
- éditer un rapport ;
- modérer un média ;
- publier une révision séparée.

## Règles

- aucune action implicite ;
- distinction claire privé/public ;
- confirmation pour les actions irréversibles ;
- raison obligatoire lorsque le contrat l’exige ;
- affichage de la provenance ;
- historique des décisions ;
- aucune validation de géométrie depuis la seule fiche média.
